# 第一版权限矩阵

匿名只改变公开展示，不改变所有权。所有权限由服务端根据会话、内部 user_id 和目标状态检查。

| 操作 | 游客 | 正常登录用户 | 内容作者 | 管理员 |
|---|---|---|---|---|
| 阅读、搜索公开内容 | 是 | 是 | 是 | 是 |
| 发布主题、回答、评论 | 否 | 是 | 是 | 是 |
| 编辑正文 | 否 | 否 | 自己的可编辑内容 | 不直接代改，使用审核操作 |
| 删除内容 | 否 | 否 | 自己的内容 | 可以，记录原因 |
| 切换解决状态 | 否 | 否 | 仅提问者 | 不代替提问者判断是否解决 |
| 举报 | 否 | 是 | 是 | 是 |
| 修改通知偏好 | 否 | 仅自己 | 仅自己 | 不代改 |
| 查看匿名真实身份 | 否 | 否 | 仅确认自己所有权 | 专用追溯操作并审计 |
| 查看删除原文 | 否 | 否 | 第一版不提供 | 删除后 30 天内，审计 |

## 状态限制（已确认规则与实现建议）

- 锁定主题：保持可读，禁止新增回答、评论和正文编辑；作者仍可删除自己的内容。
- 编辑时限：自己的内容在发布后30分钟内可编辑，超过时限只能删除重发；锁定主题仍禁止正文编辑；已解决问题不额外禁止编辑。管理员不因时限获得代改权限，仍使用审核操作。
- 匿名主题作者：在该讨论下的自答、所有评论和回复强制匿名，统一显示“楼主”（已确认）；其他参与者不受此强制规则影响。
- 已解决问题：所有用户（含提问者、管理员）禁止新增回答、评论和回复，包括回答下互动（已确认）；已有内容保留，编辑和删除按独立权限判断。
- 已删除帖子：其下全部评论及回复同步软删除（已确认）；禁止新增互动和切换解决状态。
- 已删除问题：全部回答、评论及回复同步软删除（已确认）；禁止新增互动和切换解决状态。
- 已删除回答：其下全部评论及回复同步软删除（已确认）；禁止新增评论。
- 已删除评论：递归软删除直接或间接回复它的关联评论（已确认）；保留占位，禁止新增回复，不影响祖先或无关分支。
- 隐藏主题：后代内容及附件一并停止公开展示；作者可查看自己的处理通知。
- 隐藏祖先内容（主题、回答或串根评论）：该分支下的后代内容及附件同样停止公开展示。判定沿**整条祖先链**逐级进行，而不是只对照根主题——隐藏一个回答，其下评论的图片也必须立即停止服务（已确认，2026-10-14 复核）。
- 隐藏不级联改写后代行（这与删除不同，删除有软删除级联），因此可见性必须在**每次读取**时沿链判定。所有读取、编辑、删除、评论与回复目标、附件接口共用同一判定入口（`server/internal/content/visibility.go`），不得各自实现。
- 禁言用户：可浏览、管理通知和删除自己的内容；不可新增或编辑发言。举报仍按限流规则允许。
- 封禁用户：不可登录；已有会话撤销。
- 站点设置：只有管理员可读写；SMTP密码只写不读，读取响应只说明是否已设置；验证码、限流与图片限制参数在同一处维护；每次修改写入审计，审计不记录密码明文。
- 所有列表、详情、搜索、附件和通知接口共享可见性规则。

未标为已确认的规则属于推荐默认值或待确认项；调整需同步更新需求和验收。作者删除自己的帖子、问题、回答或评论会连带删除上述范围内其他用户的下属内容，这是已确认的连带删除权限，不赋予作者独立删除无关内容的权限。
