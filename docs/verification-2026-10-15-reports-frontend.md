# 举报与审核前端入口（2026-10-15）

## 结论

第 8 项的**前端入口第一步与第二步**已实现：内容页的举报按钮 + 就地展开的举报表单，以及 `#/me/reports`「我的举报」页。个人资料页加了入口链接。

**管理端界面（举报队列、结案、隐藏/恢复、审计列表）尚未做**，因此目前只有举报者能用界面，管理员仍需 curl。第 8 项因此仍为"后端完成、前端部分完成"。

## 做了什么

- `api/reports.ts`：`createReport` 与 `listMyReports`，沿用 `request` 包装（CSRF 与 401 处理都走既有路径）。
- `components/ReportButton.tsx`：一个按钮 + 就地展开的表单（原因必填 ≤500、补充说明可选 ≤2000）。三处与后端一致的行为：
  - **未登录不发请求**，先走登录流程，而不是让请求白跑一个 401；
  - **409（已有未结案举报）当作结果展示**而不是错误弹窗——那是规则在生效，不是故障，所以与成功走同一段文案；
  - 文案明说"举报不会自动隐藏或删除内容"，避免读者以为点了就等于内容会被删。
- `views/MyReportsView.tsx`：`#/me/reports`，状态标签（待处理/处理中/已处理/不成立）、原因、补充说明、**结案说明与结案时间直接展示**（不在展开区里——那是"举报之后发生了什么"的唯一出口），目标内容 ID 与提交时间，支持加载更多。
- 接入点：主题详情页操作行（对任何登录读者开放，与"我是不是作者"无关）、个人资料页的入口、路由 `#/me/reports`（含 `routeHref` 与静态路由表）。

## 管理端界面（2026-10-15 补做）

`#/admin/moderation`：举报队列（含举报者、目标内容与封禁状态）、结案（"标记已处理并结案" / "判定不成立并结案"，处理说明必填且举报者可见）、内容处置（按内容 ID 隐藏/恢复 + 操作原因，写入审计）、审计列表（动作、操作者、原因、目标 ID，支持加载更多）。个人资料页对管理员显示入口。

界面**刻意把"结案"与"隐藏内容"做成两组动作**，因为服务端就是分开的：结案只记录对举报的决定，处置内容另走一个端点。合成一个按钮，审计就再也说不出管理员实际做了哪一种——这与后端那一段的理由是同一条。非管理员不进入该界面（服务端会 403，但让没有权限的人看到管理界面本身就是误导）；未登录先走登录流程。

### 浏览器走查记录

| 走的路径 | 结果 |
| --- | --- |
| 主题详情页的举报按钮 | 按钮存在；点击展开就地表单（`formOpened: true`） |
| 提交举报（已登录） | 表单提交后关闭并显示「已提交举报，管理员会处理；举报不会自动隐藏内容。」 |
| `#/me/reports` | 标题「我的举报」，1 条记录：标签「待处理」、举报原因、目标内容 ID |
| `#/admin/moderation` | 三节标题齐备：举报队列 / 内容处置 / 审计 |
| 管理端结案 | 填处理说明后点「标记已处理并结案」→ 提示「举报 #1 已结案（已处理）。」，举报出队，审计出现「结案举报 … 操作者 #2 原因：界面走查：已核实并结案」 |
| 管理端隐藏/恢复 | 「内容 #1 已隐藏。隐藏会连同其后代与附件一起停止公开访问。」→「内容 #1 已恢复。恢复后重新受祖先状态与删除状态约束。」；审计条数 1 → 2 → 3，动作分别为结案举报/隐藏内容/恢复内容 |
| 举报者回看结果 | `#/me/reports` 中该举报变为「已处理」，并显示**处理说明**与**结案时间**——闭环成立 |

走查中发现的文案缺陷：**恢复成功后提示仍在讲"隐藏会…"**（一句话复用了两种动作）。已修：隐藏与恢复各自一句，恢复的那句说明"重新受祖先状态与删除状态约束"。

### 仍未在浏览器里走过的

- **未登录路径**：这次浏览器带着既有会话，所以"未登录点举报应转登录页"没有走到。逻辑上 `signedIn === false` 会调用 `onUnauthenticated`，但**这只是读代码的结论，不是走查结论**。
- **409 重复举报的表现**：只走了首次提交（成功）。连续两次应显示与成功相同的文案（服务端 409 在组件里被当作结果处理），未实测。
- 举报表单的**空原因不可提交**、补充说明超长边界，只在 Go 侧与类型约束里成立。

## 结论

第 8 项的界面对用户可用：**举报 → 我的举报 → 管理端结案/隐藏 → 举报者看到结案说明 → 审计留痕**这条链路已在真实浏览器里走通。上面那三条未走过的小项不改变这个结论，但也不当作已验证。
